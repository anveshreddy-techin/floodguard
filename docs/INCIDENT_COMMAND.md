# Incident Command System (ICS) & Relief Operations

- **Incident Lifecycle:** `DETECTED` $\rightarrow$ `TRIAGED` $\rightarrow$ `VERIFIED` $\rightarrow$ `ACTIVE_RESPONSE` $\rightarrow$ `CONTAINED` $\rightarrow$ `RECOVERY` $\rightarrow$ `CLOSED`.
- **Action Tasks:** Task assignment, status tracking (`PENDING`, `IN_PROGRESS`, `COMPLETED`).
- **Shelters:** Designated high-ground relief centers with capacity monitoring.
- **Candidate Routes:** Evacuation paths with explicit disclaimers: *"Candidate route — safety not verified."*
