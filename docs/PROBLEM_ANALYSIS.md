# Problem Analysis: Mountainous Flash Floods in India

Flash floods in Himalayan and Western Ghats terrains differ fundamentally from plain riverine flooding:
1. **Extremely Low Lead Times ($T_c < 45\text{ min}$):** Cloudbursts drop immense precipitation volume on steep gradients.
2. **Multi-Hazard Cascades:** Rainfall triggers slope slips $\rightarrow$ debris dams narrow gorges $\rightarrow$ sudden breach creates a hyper-concentrated destructive surge.
3. **Data Sparsity:** Steep valleys suffer radar beam blockage and sparse in-situ telemetry.
4. **Actionability Gap:** Standard district-level alerts ($>500\text{ km}^2$) fail to inform specific village panchayats whether to evacuate lowlands.

FloodGuard AI bridges this gap with hyper-local micro-watershed modeling, multi-source fusion, explainable decision traces, and incident command integration.
