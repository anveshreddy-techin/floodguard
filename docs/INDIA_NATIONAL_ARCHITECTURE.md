# FloodGuard AI — India National Multi-Hazard Architecture

## 1. Executive Summary & National Scope
FloodGuard AI (SIH26192) is India's National Multi-Hazard Early Warning, Hyper-Local Flood Intelligence, Emergency Response, and Forensic Recovery Platform. Engineered for the Ministry of Home Affairs (MHA) and National Disaster Management Authority (NDMA), the platform covers all **28 States and 8 Union Territories** with a multi-tiered administrative hierarchy:

$$\text{India} \longrightarrow \text{State / UT} \longrightarrow \text{Division} \longrightarrow \text{District} \longrightarrow \text{Block / Tehsil} \longrightarrow \text{Gram Panchayat / Village} \longrightarrow \text{Watershed / Sensor Node}$$

## 2. Six National Disaster Hazard Zones & Regional Routing

| Disaster Zone | Primary Geography | Key Hazard Types | Regional Baseline Model |
|---|---|---|---|
| **1. Northern Himalayan** | Uttarakhand, Himachal Pradesh, J&K, Ladakh | GLOF, Cloudburst, Rock/Ice Avalanche, Debris Surge | `baseline_himalayan_v1` |
| **2. North-East & Brahmaputra** | Assam, Sikkim, Meghalaya, Arunachal, Tripura | Transboundary Surge, Riverine Inundation, Siltation | `baseline_northeast_v1` |
| **3. Western Ghats & Coastal** | Kerala, Karnataka, Maharashtra, Goa | Orographic Cloudburst, Cut-Slope Failure, Runoff | `baseline_western_ghats_v1` |
| **4. Urban Metropolitan** | Mumbai, Bengaluru, Chennai, Hyderabad, Delhi | Drainage Surcharge, Impervious Flash Flooding | `baseline_urban_v1` |
| **5. Peninsular & Central** | Odisha, Telangana, Andhra, MP, Chhattisgarh | Dam Outflow Surge, Riverine Overflow | `baseline_central_v1` |
| **6. Eastern Delta** | Bihar, West Bengal, Sundarbans | Embankment Breach, Transboundary Kosi Surge | `baseline_igp_v1` |

## 3. Data Provider Architecture & Honest Integration Status
All external institutional integrations implement the unified `BaseProvider` contract in `apps/api/src/providers/base.py`:
- **IMD AWS Telemetry**: Adapter boundary implemented. Status: `NOT_CONFIGURED` (Requires official MoU and static IP whitelisting at National Data Center, Pune).
- **CWC India-WRIS River Gauges**: Adapter boundary implemented. Status: `NOT_CONFIGURED` (Requires institutional API key at indiawris.gov.in).
- **Open-Meteo Weather API**: Status: `CONFIGURED` (Live operational forecast feed).
- **NRSC/ISRO Bhuvan SAR & GLOF Screening**: Status: `NOT_CONFIGURED` (Institutional account required).
- **State Hydrology & SDMA Portals**: Status: `NOT_CONFIGURED` (State gateway credentials required).

## 5. Truthfulness & Data Mode Hierarchy
Every API response, map layer, and dashboard metric is stamped with an explicit `data_mode`:
- `LIVE`: Verified real-time telemetry from authenticated institutional APIs.
- `HISTORICAL`: Reconstructed archive records from verified disaster events (e.g. 2013 Kedarnath, 2021 Chamoli).
- `UPLOAD`: User-submitted datasets validated via the Data Upload Center.
- `SIMULATION`: Deterministic what-if scenario models generated by the Scenario Lab.
- `DEMO`: Curated deterministic datasets for SIH evaluation without live network dependencies.
- `UNAVAILABLE`: Data stream offline or unconfigured.
