# Upstream-to-Downstream Cascade Reasoning Model

Traces hazard transitions across 5 physical stages:
1. **Stage 1 (Ridge):** Cloudburst precipitation trigger ($>40\text{ mm/h}$).
2. **Stage 2 (Slope):** Soil saturation cross-over ($S_i > 0.80$) generating surface runoff.
3. **Stage 3 (Gorge):** Debris flow remobilization down steep Strahler Order 3 tributaries.
4. **Stage 4 (Channel):** River stage height surge wave ($dH/dt > 0.4\text{ m/h}$).
5. **Stage 5 (Valley):** Floodplain alluvial fan inundation and culvert bottlenecks.
