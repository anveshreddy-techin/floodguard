## 1. Executive Summary

FloodGuard AI V10 transitions the entire software application from an administrative dashboard into a **purpose-built, high-trust, immersive disaster intelligence command system**.

Every single page in the application is engineered with a **unique visual metaphor**, eliminating uniform card boxes and establishing an engaging operational story:

$$\text{SEE} \longrightarrow \text{UNDERSTAND} \longrightarrow \text{INVESTIGATE} \longrightarrow \text{DECIDE} \longrightarrow \text{ACT} \longrightarrow \text{VERIFY}$$

## 3. Global Interaction Infrastructure

1. **Global Command Palette (`Cmd+K` / `Ctrl+K`):** Instant search and launcher across all 20 views, locations, alerts, and operational tools.
2. **Keyboard Shortcuts:** `M` (Map), `S` (Safety), `H` (Hindcast), `R` (Replay), `Esc` (Close Drawers).
3. **Collapsible Intelligence Sidebar:** Category-structured navigation with tooltips, active indicator glows, and truthfulness status badges.
4. **Universal Header:** Global Data Mode switcher (`LIVE`, `DEMO`, `SIMULATION`, `HINDCAST`), Region selector, System Telemetry pill, and Grounded Copilot trigger.
