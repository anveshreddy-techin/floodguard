# Machine Learning Strategy & Roadmap

1. **Current Baseline:** Rule-Based Hybrid Scorer (`rule_based_baseline_v1`). Transparent, zero black-box risk calculation.
2. **Next Milestone:** XGBoost Classifier trained on historical flood events (Kedarnath, Chamoli, Melamchi reanalysis).
3. **Interpretability:** SHAP (SHapley Additive exPlanations) values computed on each tree inference.
