# Uncertainty & Missing Data Intelligence

Predictions quantify what is unknown:
- Stale sensor reading ($>3\text{h}$) $\rightarrow$ Uncertainty escalated to `MEDIUM` / `HIGH`.
- Missing river gauge telemetry $\rightarrow$ Data Gap flagged in UI: *"River telemetry unavailable — using rainfall-runoff proxy."*
- Frontline operators are never given false certainty.
