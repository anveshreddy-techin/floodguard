# Hyper-Local GIS & Spatial Capabilities

- **Spatial Engine:** PostgreSQL + PostGIS (`EPSG:4326`).
- **Layers:** Catchment Watershed Polygons, Strahler Stream Orders, Village Settlement Centroids, IoT Telemetry Points, Hazard Heatmaps.
- **Spatial Queries:** Distance to river channel (Haversine), polygon containment, elevation slope calculation from DEM.
